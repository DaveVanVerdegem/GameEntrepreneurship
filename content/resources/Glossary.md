Key terms used in this course, in alphabetical order.

## Knowledge base

A collection of linked notes that you can browse and search, like this site.

## Markdown

A simple way to format plain text with symbols, such as `**bold**` or `# Heading`. See [[02 Working with Markdown]].

## Wikilink

A link written as `[[Page name]]`. It points to another note by its name, so you don't need to know where the file is stored.
